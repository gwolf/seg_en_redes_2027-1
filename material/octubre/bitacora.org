* 2026.10.06
** Temas
- Captura de certificados para poder analizar conexiones TLS: Variable de
  ambiente =SSLKEYLOGFILE=:
  #+begin_src sh
    $ export SSLKEYLOGFILE=/tmp/tls-keys.log
    $ chromium https://sitio-a-probar.org/
  #+end_src
  Ojo: *que sea un navegador nuevo*, no una nueva pestaña de uno ya
  instanciado. Va a almacenar la negociación de llave de sesión para /todos
  los sitios/ que se abran durante la sesión.
- Captura de tráfico cifrado, como siempre: =tcpdump -w /tmp/salida.pcap
  tcp port 443 or udp port 443=
- Seguimiento de paquetes:
  - Con =wireshark=:
    - =Edit= → =Preferences= → =Protocols= → =TLS= → =(Pre)-Master-Secret
      log filename= → =/tmp/tls-keys.log=
    - Abrir el archivo de captura, ya permite revisar los campos cifrados
  - Con =tshark=:
    - =$ tshark -r captura.pcap -o "tls.keylog_file:/tmp/tls-keys.log" -Y "http2" -T fields -e frame.number -e http2.header.name -e http2.header.value=
