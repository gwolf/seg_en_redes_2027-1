* 2026.10.06
** Temas
- Captura de certificados para poder analizar conexiones TLS: Variable de
  ambiente =SSLKEYLOGFILE=:
  #+begin_src sh
    $ export SSLKEYLOGFILE=/tmp/tls-keys.log
    $ chromium https://sitio-a-probar.org/
  #+end_src
  Ojo: *que sea un navegador nuevo*, no una nueva pestaña de uno ya
  instanciado. Va a almacenar la negociación de llave de sesión para /todos
  los sitios/ que se abran durante la sesión.
- Captura de tráfico cifrado, como siempre: =tcpdump -w /tmp/salida.pcap
  tcp port 443 or udp port 443=
- Seguimiento de paquetes:
  - Con =wireshark=:
    - =Edit= → =Preferences= → =Protocols= → =TLS= → =(Pre)-Master-Secret
      log filename= → =/tmp/tls-keys.log=
    - Abrir el archivo de captura, ya permite revisar los campos cifrados
  - Con =tshark=:
    - =$ tshark -r captura.pcap -o "tls.keylog_file:/tmp/tls-keys.log" -Y "http2" -T fields -e frame.number -e http2.header.name -e http2.header.value=

privadas. ¿Qué pasa cuando una llave privada que supuestamente es de buena

** Vulnerabilidades de /alto impacto/ en PHP

El martes 20 por la tarde se anunció que se estaba preparando una
/divulgación coordinada/ para una actualización de emergencia de PHP, para
las 14:00 UTC del miércoles 21.

Como era de esperarse (tristemente), los ataques comenzaron a darse a
conocer antes de la hora acordada, llevando a la necesidad de una
actualización de emergencia descoordinada. Esta vulnerabilidad se conoce
como [[https://www.php2shell.com/][PHP2Shell]], y se le asignaron los CVEs [[https://nvd.nist.gov/vuln/detail/cve-2026-109618][CVE-2026-109618]] y
[[https://nvd.nist.gov/vuln/detail/cve-2026-109619][CVE-2026-109619]], con severidad CVSS 9.2 “critical”.

Ambos ataques provienen de errores de manejo de memoria: /uso de una región
de memoria después de liberarla/ (/use-after-free/).

- [[https://ma.ttias.be/php-cve-2026-109618-early-mitigation/][PHP CVE-2026-109618 and CVE-2026-109619: early mitigation steps]], de
  Mattias Geniar: Explicación de los bugs en cuestión y ayuda para mitigar
  / corregir el problema.
- [[https://github.com/eness/php2shell-CVE-2026-109618-CVE-2026-109619-PoC][Prueba de concepto (PoC) de explotación]]
- [[https://community.owasp.org/vulnerabilities/Using_freed_memory][OWASP: Using freed memory]]
- [[https://learn.snyk.io/lesson/use-after-free/?ecosystem=cpp][Use after free]], tutorial sencillo para entender el tipo de ataque (Snyk
  Learn)
- [[https://cybersecuritynews.com/use-after-free-vulnerability/][What is Use-After-Free Vulnerability? – Impact and Mitigation]], otro
  tutorial sencillo (Cybersecurity News)
